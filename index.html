Cloudflare 云端真实数据库绑定向导

ProtoView 采用完全 Serverless 云原生架构。为了让网页拥有云端多用户隔离与存储能力，只需在 Cloudflare 控制台进行一次性轻量绑定：

1 在 Cloudflare 仪表盘创建 D1 数据库与 R2 存储桶
  • D1 数据库：打开 Cloudflare 控制台 -> Storage & Databases -> D1 -> 点击「创建数据库」，名称填 protoview-db。
  • R2 存储桶：打开 R2 对象存储 -> 点击「创建存储桶」，名称填 protoview-bucket。
2 在 Pages 项目中绑定变量 (函数设置)
打开 Workers 和 Pages -> 点击您的项目 -> 切换到 设置 (Settings) -> 函数 (Functions)：
  • 在 D1 数据库绑定 处添加：变量名称严格填 DB，数据库选择刚创建的 protoview-db。
  • 在 R2 存储桶绑定 处添加：变量名称严格填 PROTO_BUCKET，存储桶选择 protoview-bucket。
💡 变量名必须为大写 DB 和 PROTO_BUCKET，系统后端函数将自动感知并直连。
3 一键初始化数据表 (创建 users & sessions 表)
完成上述绑定后，直接在本管理后台点击「一键初始化数据表」按钮，系统即可全自动在 D1 中完成建表，无需在本地安装 Wrangler 命令行！
D1 建表 SQL 脚本 (d1-schema.sql) 
-- 1. 用户基本信息表 (仅保存用户名与加盐哈希密码)
CREATE TABLE IF NOT EXISTS users (
    username TEXT PRIMARY KEY,
    salt TEXT NOT NULL,
    password_hash TEXT NOT NULL,
    created_at INTEGER NOT NULL,
    updated_at INTEGER NOT NULL
);

-- 2. 用户登录会话表 (30天有效期 Token)
CREATE TABLE IF NOT EXISTS sessions (
    token TEXT PRIMARY KEY,
    username TEXT NOT NULL,
    created_at INTEGER NOT NULL,
    expires_at INTEGER NOT NULL,
    FOREIGN KEY (username) REFERENCES users(username) ON DELETE CASCADE
);

-- 3. 通信协议云端存储表 (支持 D1 独立持久化，免 R2 强依赖)
CREATE TABLE IF NOT EXISTS protocols (
    key TEXT PRIMARY KEY,
    username TEXT NOT NULL,
    name TEXT NOT NULL,
    type TEXT NOT NULL DEFAULT 'ARINC429',
    product TEXT DEFAULT '',
    data TEXT NOT NULL,
    updated_at INTEGER NOT NULL
);

-- 4. 产品与设备型号元数据表
CREATE TABLE IF NOT EXISTS user_products (
    username TEXT PRIMARY KEY,
    data TEXT NOT NULL,
    updated_at INTEGER NOT NULL
);

-- 5. 索引优化
CREATE INDEX IF NOT EXISTS idx_sessions_username ON sessions(username);
CREATE INDEX IF NOT EXISTS idx_sessions_expires_at ON sessions(expires_at);
CREATE INDEX IF NOT EXISTS idx_protocols_username ON protocols(username);
